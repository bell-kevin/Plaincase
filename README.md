# Plaincase
“Promise-to-proof” workspace for everyday disputes, claims, repairs, refunds, and billing problems. It connects timelines, original evidence, SHA-256 fingerprints, commitments, deadlines, outcomes, &amp; open-format case packs. Everything runs in the browser with React, Dexie/IndexedDB, Web Crypto, and JSZip—no backend, account, analytics,  or paid API
